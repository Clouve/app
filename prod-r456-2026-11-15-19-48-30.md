### Release 4.5.6:

- **AI Assistant modes.** Regular mode is a chat that asks before it changes anything; Advanced is the terminal. Paid deployments open in Regular; trials and free services stay in Advanced.
- **Allow without asking.** A switch in Regular mode, off by default, lets the assistant run steps without an OK. Sensitive steps still ask and say why.
- **Trial card.** On a trial or free service, Regular's card says it needs a paid plan with AI usage included.
- **Resizable sidebar.** Drag its edge to change the width; a round chevron folds and opens it.
- **No cloud picker.** The provider dropdown, Cloud tab and Cluster Type are gone. Region shows on the Status tab and on the install page's Review tab.
- **Refusals.** If the model refuses a request in Regular mode, the conversation stops with a notice and "Start a new conversation".
- **Clouve support.** Clients see "Clouve support" where a Super Admin acted for them.
- **Database password rotation.** Client admins rotate a deployment's database password from its Settings tab. Tabs work with the keyboard.
- **HTTPS redirect.** After the ingress swap, plain HTTP on an app's default host redirects to HTTPS when it has a custom domain.
- **3 AM PT.** Daily backups on US clusters run at 3:00 AM PT and the status run at 3:02 AM PT.
- **Write-only credentials.** Saved Git tokens, pass-through values and secret defaults show as Saved or Not set. Listing screenshots must be images.
- **App images.** ownCloud 10.16.6 with MariaDB 12.3; Gibbon and Moodle carry patched libraries.
- **Client Details.** The top of the page is one band of facts with the details in a grid.
- **Staff tools.** Super Admins get a Spot switch per deployment and an unused-uploads purge per organization.
- **Upgrade.** Upgrade re-renders a deployment from the new listing version, keeping plan, sizes, price, disks and settings, with a backup first and a rollback if it fails.
- **Refund take-backs.** Control Panel refunds take back the publisher's or partner's share, once each environment's switch is on.
- **Staff Duplicate.** A staff Duplicate starts its copy, with the AI Assistant off; a paused source's copy stays paused.
- **Super Admin view.** On a client's deployment page a Super Admin sees only what they can do there.
- **Traefik.** Traefik replaces ingress-nginx on cluster-1, with setup, migrate, rollback and teardown actions.
- **Registered clusters.** No cluster-admin token is stored; setup uses a one-year client certificate.
- **Toolchain.** Go 1.27.4, source-built kubectl, cmctl and Velero, and Helm 4.3.2: 0 HIGH and 0 CRITICAL in the clv-agent and clv-proxy images.
- **iono.** iono runs on node:22.23.5-alpine and starts faster.
