### Release 4.3.0:

- **TLS & certificate overhaul.** Consolidated onto a single Google Public CA (`gcp-prod`) issuer and a cluster **wildcard cert** for default subdomains — per-app TLS blocks are gone. New `inspect-certs` / `renew-certs` cluster actions, plus an orphan-cert sweep.
- **Marketplace for developers.** Application **visibility controls** (public/private) with a badge across the dashboard, staging-event notifications + staging-history access, short descriptions, and compact pricing rows with tier chips.
- **Deployment lifecycle UX.** Paused/inactive deployments are handled explicitly, the running version shows in the logo overlay, agent status can be overridden, and a hidden-mode session-leakage bug is fixed.
- **Strato cluster-management refactor.** Restructured action/lib layout with a grouped two-level action menu, teardown scripts, Harbor upgrade + overlay-drift detection, Firestore-backed repo-managed k8s credentials, and an OIDC groups claim.
- **Local dev environment.** Bootstrap now supports Fedora, BTRFS Timeshift snapshots, inotify-limit tuning, and non-interactive mode; added a Local Cluster Debugging Guide.
