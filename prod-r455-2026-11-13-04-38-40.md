### Release 4.5.5:

- **Duplicate.** It works again for a deployment without a custom domain, and each promotion removes the copies failed duplicates left.
- **Same-day cancels.** They refund even while Braintree starts settling the charge, and a retried cancel never refunds twice.
- **Trials for Users (W11).** A User sees "Only <organization>'s admins can complete purchases." instead of SUBSCRIBE NOW, and their trial emails ask an admin to subscribe.
- **Restore (W19).** It hides on a backup that expires within the hour.
- **Last sign-in (W10).** It shows the server's time, so the browser's offset no longer shifts it.
- **Cancel email (W23).** It names an AI Assistant charge a cancel keeps, and counts two or more refunds.
- **Custom domains (W24).** A deployment whose listing became a bundle keeps its domain.
- **Install-time values (W14).** Apostrophes, `&`, `<` and line breaks reach the app as typed.
- **Names ending in ".".** Emails, toasts and receipts no longer print "Inc..".
- **Copy emails.** A copy into another organization doesn't name its source, and a Super Admin's copy reads "Clouve support made a copy of ...".
- **Listing pages.** A publish shows within about 2 minutes.
- **Docs (W28).** They explain outage emails and the Administrator and User roles.
- **Uploads (W15).** File names with `%`, `#`, `?` or a backslash work.
- **Pauses (W13).** A pause whose result got lost heals 30 to 35 minutes later.
- **Attachments.** A ticket lists only its own organization's uploads.
- **App images.** WordPress debug stays off, Odoo's database manager is locked, no image has baked SSH host keys, MySQL and MariaDB run tini, and no database password reaches a log.
- **Skills.** They keep passwords off command lines, send credential rotation to Clouve support, and never ask a customer to restart a pod.
- **Publisher logos (W21).** A logo must be one of the organization's own uploads.
- **Listing wizard (W18).** Next and Save wait for the draft to load.
- **Install-time defaults (W14).** A line break is refused at save.
- **Image paths.** Icon, logo and screenshot paths with a backslash or control character are refused.
- **Compose limits.** Oversized compose files are refused, each with its own sentence.
- **createApplication (W8).** The unused mutation is gone.
- **Tenant guard (W1).** A Token holder can't route other hosts to their namespace or have cert-manager or Helm act for them.
- **Run on Spot (T14).** A staff-only switch on Client Details for new installs.
- **Agents (W26).** They reach only the tickets they serve.
- **Super Admin clone (W27).** Into any client organization, with a searchable picker.
- **Ingress and certificates (R8).** ingress-nginx v1.15.1 (three HIGH CVEs fixed) and cert-manager v1.21.3.
- **Registered clusters (R7, R6, T2).** Workload Identity with no key, a fence on the deployer's writes, and a readiness check of every guard.
- **Monitoring (R9, R10, T3).** Alerts name their cluster, each project has a dashboard, and a stuck create job says so.
- **Harbor (#154).** It keeps cert-manager's certificate across helm runs, and a run no longer gets it issued twice.
- **build.sh.** It refuses to push to UAT's or prod's Harbor without a dated tag.
- **Agent images.** They carry python3 and use Helm 4's list, and upgrade-ingress handles Harbor's short-host redirect.
- **Clients list (#166).** Deleted deployments count apart.
- **Snapshots (#144).** Copies and restores keep restore snapshots straight, and a deleted namespace's snapshot contents go too.
- **Gate reads.** New read-only actions: inspect-tenant-guards, inspect-snapshots and four data counts.
- **Logs (W3, W4, W5).** No addresses in thermo's lines, and no Harbor answer bodies in errors.
- **Dependencies (V1, W7).** thermo, iono and meso have 0 critical and 0 high advisories, and strato's agent binary is clean.
- **The rig.** Its seed drops the retired password, and a Token kubeconfig keeps kind's CA.
- Full notes: releases/RELEASE_NOTES_v4.5.5.md in the docs repo.
