### Release 4.3.2:

- **Platform-wide dependency modernization (thermo · meso · iono).** A coordinated, coverage-gated upgrade across the three Node services: committed lockfiles + pinned base images + `npm ci` for reproducible builds, real test/coverage baselines, then the breaking framework majors one at a time — **Express 4→5, Apollo Server 4→5, Apollo Client 3→4, @rjsf 5→6, Vite 6→8, react-router 7→8**, plus GCP/utility majors (Pub/Sub 5, Firestore 8, puppeteer 25, dockerode 5, multer 2, uuid 14…). **All high/critical advisories cleared** in iono and thermo (dropped `firebase-tools`, −303 packages; scoped micromatch/braces override; lodash security line). Full detail in the appendix below.
- **Harbor robot-secret persistence & reveal.** Registry robot secrets are now persisted in **Google Secret Manager** (thermo) and can be revealed on demand in the UI (meso) — masked reveal + rotate-to-capture — for both developer and admin/reviewer registry accounts.
- **First Tier Agent client-user editing.** FTAs (role `agent_admin`) and super admins can edit a client user's profile from Client Details; a new `users.auth_provider` column protects SSO-backed accounts from email changes that would orphan their Google/Harbor identity.
- **Tunnel wildcard-host routing.** The in-cluster rathole client (strato) and the tunnel server now accept **wildcard hostnames** in tenant validation, nginx, and ingress routing — removing per-host static config.
