### Release 4.4.1:

- **AI Assistant.** The assistant's instructions no longer hold any database, admin or root password: only hosts, database names and users, and names are filled in. On listings built from stock images it is ready in about two minutes instead of failing after about 16, because it no longer waits for containers that don't run Clouve's ops shell. It also knows who deployed it.
- **Apps.** Odoo's assistant backs up, installs modules and restarts Odoo with commands that work on Odoo 19, and Odoo no longer warns about its empty add-ons folder. A new Education Kit starts on the current school year. A password the assistant sets for a Moodle user synced from Gibbon keeps working.
- **Publishing.** A published app no longer shows "Missing" while its marketplace status loads. The compose import keeps plain values such as MYSQL_DATABASE=wordpress as values, and makes secret keys that Kubernetes accepts from any compose file. The publish wizard says which containers the assistant can reach. The Help page has documentation, how-to videos and the support form.
- **Fixes.** An organization's first ticket is numbered 1, not 0.
- **Clean-up.** thermo won't start without its own session secret. The database drops the authorized-user table that 4.4.0 kept as a rollback record, its read-only view, and an unused AI settings column.

Full notes: releases/RELEASE_NOTES_v4.4.1.md in the docs repo.
